# xmoney_android

Android implementation of the [xMoney](https://xmoney.com) Flutter payments SDK.

Depend on [`xmoney`](https://pub.dev/packages/xmoney). This package is a federated implementation and is not used directly.

Native artifacts: Maven `com.xmoney:paymentsheet`, `paymentelement`, and `googlepay` **1.0.0**.
